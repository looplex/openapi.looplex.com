# Build de uma nova API

Toda API desse projeto é renderizada de acordo com o arquivo `.json` que é compilado de acordo com o arquivo dessa API disponível na pasta `/app/<version>_<api_name>/<api_name>.yaml`.  
> Nota: o arquivo `.json` não precisa ter o mesmo nome do arquivo `.yaml` da API.  

As APIs criadas estão definidas no arquivo `/app/project.json`.
